# Lakshya Design Co.

A premium, modern, and Apple-style luxury website designed for high-end graphic design services.

## 🎨 Theme & Styling
- **Background:** Deep Tech Black
- **Accents:** Emerald Green & Luxury Gold
- **UI Style:** Glassmorphism, Clean Spacing, Fast Loading, and 100% Mobile Responsive

## 🚀 Features
- Multi-page structural navigation
- One-click premium WhatsApp and Call integrations
- Custom responsive grids for Portfolio and Services
- Clean, search-engine-optimized structure (SEO Friendly)

## 📁 File Structure Setup
- All layouts use `assets/css/style.css` for centralized premium styling.
- Core interactive components are driven by vanilla JavaScript in `assets/js/script.js`.
